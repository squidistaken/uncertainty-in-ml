\section{Background}
\subsection{Guassian Processes (GP)}
% Define GP as a prior over functions; any finite set of points is jointly Gaussian
% Describe the kernel function (RBF/Matérn) and its role in encoding smoothness/structure
% State the predictive distribution: posterior mean and variance given observed data
Gaussian Processes (GPs) are a non-parametric Bayesian approach to regression that define a prior over functions rather than a finite set of parameters. A GP is fully specified by a mean function $m(x)$ and a covariance function (kernel) $k(x, x')$, such that for any finite set of inputs $\{x_i\}_{i=1}^n$, the corresponding function values follow a multivariate Gaussian distribution:
\[
f(x) \sim \mathcal{GP}(m(x), k(x, x'))
\]
\[
\mathbf{f} = [f(x_1), \dots, f(x_n)]^\top \sim \mathcal{N}(\mathbf{m}, \mathbf{K})
\]

The kernel function encodes assumptions about the structure of the function, such as smoothness and periodicity. Common choices include the Radial Basis Function (RBF) kernel and the Matérn kernel. For instance, the RBF kernel is defined as:
\[
k(x, x') = \sigma^2 \exp\left(-\frac{\|x - x'\|^2}{2\ell^2}\right),
\]
where $\ell$ controls the length-scale (smoothness) and $\sigma^2$ controls the variance.

Given observed data $\mathcal{D} = \{X, y\}$ and a GP prior, the posterior predictive distribution at a new input $x_*$ is Gaussian:
\[
p(f_* \mid x_*, X, y) = \mathcal{N}(\mu_*, \sigma_*^2),
\]
where the posterior mean $\mu_*$ and variance $\sigma_*^2$ quantify both the prediction and its uncertainty. This closed-form uncertainty estimate makes GPs particularly attractive for probabilistic forecasting tasks.


\subsection{Variational Inference and ELBO}
% Explain why exact GP inference is O(n^3) and infeasible for ~7500 trading days
% Describe inducing points as a sparse approximation that compresses the data
% ELBO as the training objective: maximised during training, implicitly minimises NLL
Despite their strong theoretical properties, exact GP inference is computationally expensive, scaling as $\mathcal{O}(n^3)$ due to the inversion of the covariance matrix. In financial applications such as modeling approximately 7,500 trading days of S\&P 500 data, this cost becomes prohibitive.

To address this, sparse variational Gaussian Processes introduce a set of $m \ll n$ inducing points that act as a compressed representation of the full dataset. These inducing points, denoted $\mathbf{Z}$ with corresponding function values $\mathbf{u}$, approximate the true posterior by projecting the full GP onto a lower-dimensional latent space.

Training is performed by maximizing the Evidence Lower Bound (ELBO), which can be written as:
\[
\mathcal{L}_{ELBO} = \mathbb{E}_{q(f)}[\log p(y \mid f)] - \mathrm{KL}(q(u) \| p(u)),
\]
where $q(u)$ is the variational distribution over inducing variables. Maximizing the ELBO balances data fit and regularization, and is closely related to minimizing the negative log-likelihood while penalizing model complexity. This framework enables scalable GP inference while retaining principled uncertainty estimation.


\subsection{MC Dropout as Approximate Bayesian Inference}
% Gal & Ghahramani (2016): applying dropout at inference time approximates a Bayesian posterior over network weights
% Describe how N=50 stochastic forward passes produce a predictive distribution
% Predictive mean = sample mean, predictive variance = sample variance
Monte Carlo (MC) Dropout, introduced by \cite{gal2016dropout}, interprets dropout at test time as an approximate Bayesian inference technique over neural network weights. By enabling dropout layers during inference, each forward pass corresponds to sampling from an approximate posterior over the network parameters.

Given an input $x$, we perform $N$ stochastic forward passes (typically $N=50$), producing predictions:
\[
\{\hat{y}^{(1)}, \hat{y}^{(2)}, \dots, \hat{y}^{(N)}\}.
\]

The predictive distribution is then approximated using:
\[
\mathbb{E}[y] \approx \frac{1}{N} \sum_{i=1}^{N} \hat{y}^{(i)}, \quad
\mathrm{Var}(y) \approx \frac{1}{N} \sum_{i=1}^{N} \left(\hat{y}^{(i)} - \bar{y}\right)^2.
\]

This approach provides a computationally efficient way to estimate epistemic uncertainty in deep learning models without requiring explicit Bayesian neural networks.


\subsection{Uncertainty Calibration}
% Define calibration: predicted confidence should match empirical frequency
% NLL as a proper scoring rule: penalises both overconfidence and underconfidence
% ECE as the miscalibration gap between predicted and observed confidence
% PIT histogram as a visual calibration diagnostic: uniform = well-calibrated
Uncertainty calibration refers to the agreement between predicted probabilities (or confidence levels) and observed empirical frequencies. A well-calibrated model produces predictions such that, for all instances assigned a confidence of $p$, approximately $p$ proportion of those predictions are correct.

Negative Log-Likelihood (NLL) is a proper scoring rule that evaluates probabilistic forecasts by penalising both overconfident and underconfident predictions:
\[
\mathrm{NLL} = -\frac{1}{N} \sum_{i=1}^N \log p(y_i \mid x_i).
\]
Lower NLL indicates better-calibrated predictive distributions.

Expected Calibration Error (ECE) quantifies miscalibration by partitioning predictions into confidence bins and comparing predicted confidence with empirical accuracy:
\[
\mathrm{ECE} = \sum_{b=1}^B \frac{|B_b|}{N} \left| \mathrm{acc}(B_b) - \mathrm{conf}(B_b) \right|.
\]

Additionally, the Probability Integral Transform (PIT) histogram provides a visual diagnostic tool for calibration. For a well-calibrated model, the transformed values should follow a uniform distribution. Deviations from uniformity indicate systematic over- or under-dispersion in the predictive uncertainty.

\subsection{Conclusion of Background}
The methods introduced in this background section form the theoretical foundation for evaluating both predictive performance and uncertainty quality in financial time series forecasting. While traditional approaches to stock return prediction primarily focus on point estimates, this project emphasizes that reliable decision-making in financial markets depends equally on well-calibrated uncertainty estimates.

Together, these methods establish a coherent framework that links probabilistic modeling, scalable Bayesian approximation, and uncertainty evaluation. This framework directly motivates the project’s objective: not only to forecast next-day S\&P 500 returns, but also to rigorously compare how different modeling paradigms quantify and calibrate uncertainty in a highly noisy and non-stationary financial environment.
